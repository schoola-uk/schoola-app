## How to build each link (2 mins per product)
1. Log into Amazon.co.uk with your Associates account
2. Turn on SiteStripe (top bar) > Get Link > Text
3. Search using the Exact Search Term below, filter: 4★+ , 100+ ratings, Prime
4. Pick 2-3 options per row: 1x budget, 1x mid-range/bestseller, 1x premium
5. Copy SiteStripe short link, paste into Tracking column
6. Add `&tag=schoola-21` if using clean URLs

UK disclosure (required): Add at top of every hub page: "As an Amazon Associate I earn from qualifying purchases."
